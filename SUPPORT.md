# Support

AppKit is a starter kit and reference architecture. Support is community/project-maintainer best effort unless a separate commercial or organizational support policy is added later.

## Before asking for help

Please check:

- [README.md](./README.md)
- [CONTRIBUTING.md](./CONTRIBUTING.md)
- app and package READMEs
- [docs/cli-auth.md](./docs/cli-auth.md)
- existing issues and pull requests

## Good support requests include

- what you are trying to do
- what you expected to happen
- what actually happened
- steps to reproduce
- relevant terminal output or screenshots
- operating system and Node/pnpm versions
- app/package area, if known

## Bugs

Use the bug report issue template.

Please include a minimal reproduction when possible.

## Feature requests

Use the feature request issue template.

Please describe the user problem first, then the proposed solution.

## Security issues

Do not open public support issues for vulnerabilities. Follow [SECURITY.md](./SECURITY.md).

## Questions

If GitHub Discussions are enabled, use discussions for open-ended questions and design ideas. If not, open an issue and choose the closest template.
